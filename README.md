# Referto Baskin

App per tablet per compilare il referto ufficiale Baskin (Rev. 3.0.8): liste R, gara, firme e PDF. Funziona offline dopo la prima apertura. Tutti i dati restano sul dispositivo.

Apri https://cavallidiegocavalli.github.io/referto-baskin/ con Safari su iPad, poi Condividi → Aggiungi alla schermata Home.
